# ADR-0001: Independent Validation repository and real FIT-03 packaging

- **Decision:** `blackwhi-fit-stdlib-validation` is an independent Git repository under the non-Git parent directory `blackwhi-fit-stdlib`.
- **Runtime:** Starlark from BlackWhi Rust engine (0.14.2). FIT sources are pure; no host capabilities or I/O.
- **Distribution:** Current FIT-03.3 contract builds a runnable package containing a program and a versioned library. Export both manifest `fit-library.json` and verified package envelope; do not claim that a library-only publishing contract exists.
- **Dependency direction:** Types predicates have no dependency on Results & Errors.
- **Versioning:** `com.blackwhi.std.validation.core@0.1.0`, SemVer.
- **Licensing:** Apache License, Version 2.0 approved for original FIT Standard Library code on 2026-11-11. GitHub source publication and signed FIT Registry publication are distinct operations.
- **Git history:** Local Git commits must not impersonate the lead developer; attribution is recorded in CREDITS.
